# Converter Project

Conversor de unidades básico implementado en Java.

## Características
- Conversión de temperatura (Celsius a Fahrenheit)
- Conversión de longitud (metros a pies)
- Interfaz de línea de comandos

## Cómo ejecutar
```bash
mvn clean compile
mvn exec:java -Dexec.mainClass="org.converter.Main"
```
